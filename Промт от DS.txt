Резюме наших выводов
1. Технология
Astro — отлично подходит для лендинга с формой, даёт быстрый статический HTML.

Вёрстка простая, сборка через npm run build, выгрузка на хостинг.

2. Сбор заявок (для РФ)
Использовать Яндекс Формы — бесплатно, работает без ограничений, есть уведомления на почту.

Код формы вставляется на сайт через iframe или готовый HTML-код.

3. Защита сайта
Подключить Solar Space (бесплатный WAF/Anti-DDoS от ГК «Солар») — до 5000 посетителей/месяц.

Настроить SSL-сертификат, бэкапы, сложные пароли.

4. Юридическая база (обязательно к размещению на сайте)
«Политика в отношении обработки персональных данных» — основной документ.

«Согласие субъекта персональных данных на обработку персональных данных» — чекбокс под формой.

Согласие на рассылку (если планируете) — для рекламных сообщений.

Cookie-баннер — уведомление об использовании файлов cookie.

5. Роскомнадзор
Подать уведомление о начале обработки ПД до добавления формы на сайт.

Подача через Госуслуги занимает 10–15 минут.

6. Стратегия запуска
Сначала запустить сайт без формы (визитка).

Подготовить форму, но скрыть/заблокировать.

В день активации: разместить документы → подать уведомление в РКН → опубликовать форму.

Промт для нейросети
Если хотите получить готовый план действий или текст документов, вот промт:

«Ты эксперт по запуску лендингов в России. Составь чек-лист из 10 пунктов для запуска одностраничного сайта на Astro с формой сбора заявок, чтобы я ничего не упустил. Включи технические шаги (хостинг, SSL, защита, скорость), юридические документы для сайта (Политика конфиденциальности, Согласие на обработку ПД, Cookie) и порядок уведомления РКН. В конце напиши краткий план действий по дням (день 1, день 2...). Ответ структурируй по пунктам без воды.»

Можете скопировать и вставить в любой AI-помощник для детализации. Если нужен будет более конкретный промт под какой-то этап — скажите, уточню.
