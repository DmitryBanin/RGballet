# RG Ballet

Адаптивный сайт балетной школы по макетам Figma для разрешений 1920 и 360 px с собственной адаптацией промежуточных размеров.

## Технологии

- Astro.
- HTML, обычный CSS и Vanilla JavaScript.
- Без React, UI-фреймворков и Tailwind.
- Изображения сайта: `public/images`.
- Шрифты: `public/fonts`.
- Исходные макеты и другие локальные материалы: `.initial_data` — не входят в Git.

## Локальная разработка

```bash
npm install
npm run dev
```

Проверка производственной сборки:

```bash
npm run build
```

Готовые статические файлы создаются в `dist`.

## Размещение

Планируется российский виртуальный веб-хостинг. Рассматриваются Timeweb и SpaceWeb. Домен `rgballet.ru` зарегистрирован через REG.RU; в дальнейшем планируется переоформление домена и связанной инфраструктуры на ИП.

Предполагаемая схема: локальная разработка → GitHub → сборка Astro → российский хостинг. Подключение GitHub и автоматический деплой через GitHub Actions запланированы на последующих этапах.
