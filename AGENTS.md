# Правила работы

* Общайся только на русском.
* В обычных ответах пиши кратко.
* Код предоставляй полностью, когда изменяется целый файл.
* Не сокращай важные технические объяснения.
* Не пиши код, сперва алгоритм действий.
* Если есть упущение в действиях задай вопрос.
* Пиши действия которые мне нужно сделать поступательно.
* Перед изменением файла сначала составь план.
* Не меняй архитектуру проекта без необходимости.
* Не создавай новые зависимости без согласования.
* Используй существующий стиль кода.
* После завершения перечисли изменённые файлы.
* Перед началом работы ознакомься с:

  * README.md
  * docs/TZ.md
* Если в требованиях есть противоречия, сначала укажи на них
* Новые нерешённые вопросы записывай в `docs/QUESTIONS.md`.
* Принятые технические решения записывай в `docs/DECISIONS.md`.
