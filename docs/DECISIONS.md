# Принятые технические решения

## Стек проекта

- Astro.
- HTML.
- CSS без CSS-фреймворков.
- Обычный JavaScript без TypeScript.
- Vanilla JS используется только для меню, модального окна формы, слайдеров и другой интерактивности.
- React, Vue и другие UI-фреймворки на первом этапе не используются.
- Проект собирается как статический сайт командой `npm run build`.
- Результат сборки из папки `dist` должен подходить для обычного виртуального хостинга.

## Порядок разработки

1. Создание Astro-проекта.
2. Подключение шрифтов.
3. Настройка глобальных цветов, размеров и контейнера.
4. Создание `BaseLayout`.
5. Шапка сайта.
6. Первый экран.
7. Остальные секции сверху вниз.
8. Подвал.
9. Мобильное меню.
10. Модальное окно записи.
11. Проверка адаптива в диапазоне от 360 до 1920 px.
12. SEO: `title`, `description`, favicon, sitemap и robots.
13. Яндекс Метрика.
14. Проверка сборки командой `npm run build`.
15. Публикация содержимого папки `dist`.

Сначала должна быть завершена и проверена статическая главная страница. Форма, аналитика и размещение не выполняются на начальном этапе.

## Шрифты

- Шрифты хранятся локально в `public/fonts`, без подключения внешних CDN.
- Основной веб-формат — WOFF2, WOFF используется как резервный.
- Для Manrope подключены начертания 300, 400, 500, 600 и 700.
- Для Corvetta подключено начертание 400.
- Для Cormorant Garamond подключено начертание 700.
- Используется `font-display: swap`.
- Право использования Corvetta необходимо подтвердить до публикации сайта.

## Цветовая палитра

- Основной текст: `#232323`.
- Основной фон и инверсные элементы: `#FFFFFF`.
- Основной голубой акцент: `#5BA9E1`.
- Дополнительный голубой акцент: `#5FA8D3`.
- Градиент кнопок строится между `#6DB8FF` и `#3379D7`.
- Обводка основной кнопки: `#CFE7FA`.
- Тень градиентных кнопок: `#357CD8`.
- Техническая подложка фотографий: `#D9D9D9`.
- Локальный чёрный элемент: `#000000`.
- Оба близких голубых цвета сохраняются до визуального сравнения с макетом.
- Угол и положение точек градиента, а также геометрия тени будут добавлены после получения точных параметров из Figma.

## Структура главной страницы

- Общая HTML-оболочка и подключения глобальных стилей вынесены в `BaseLayout.astro`.
- Содержимое страницы ограничено общей оболочкой шириной `1920px` и центрируется на более широких экранах.
- Оболочка не использует `overflow: hidden`, чтобы не обрезать выпадающие и декоративные элементы.
- Внутренняя ширина контента составляет `1840px` с боковыми отступами до `40px`.
- Шапка, первый экран, все смысловые секции и нижний блок сайта реализуются отдельными Astro-компонентами.
- Повторяющиеся градиентные кнопки вынесены в компонент `GradientButton.astro`.
- Одинаковые информационные баннеры объединены в компонент `Banner.astro`; заголовок, подпись кнопки и идентификатор заголовка передаются через props.
- Галерея учениц и раскрытие дополнительных возможностей реализуются на Vanilla JavaScript без сторонних зависимостей.
- Изображения и SVG сайта хранятся в `public/images` и доступны по пути `/images/...`.
- Мобильное меню и кнопка записи на текущем этапе имеют только внешний вид; интерактивность будет добавлена отдельным шагом.
- Иконка мобильного меню реализована встроенным SVG и анимируется из трёх линий в крестик без растрового изображения.

## Контактные данные

- Контактные данные сайта хранятся централизованно в `src/config/contacts.js`.
- Компоненты получают телефон, email и ссылки на социальные сети из конфигурации, без дублирования значений в разметке.
- Значок адреса и текст адреса в подвале открывают карточку организации в Яндекс Картах на компьютере, системный выбор приложения карт на Android и Apple Maps на iPhone или iPad.

## Отзывы

- Ссылка «Смотреть все отзывы» открывает раздел отзывов карточки RG Ballet в Яндекс Картах.
- Отзывы добавляются в отмеченное место массива `comments` компонента подвала; карточки и навигационные точки формируются из него автоматически.
- Длинный текст отзыва сокращается внутри карточки; кнопка «Читать полностью» раскрывает его на сайте и меняется на «Свернуть».
- Высота нижнего блока увеличивается по содержимому раскрытого отзыва без наложения на контакты и форму.

## Среда разработки

- Текущая рабочая версия Node.js: 24.16.0.
- Текущая рабочая версия npm: 11.13.0.
- Используется npm registry `https://npm-mirror.gitverse.ru`.
- Указанные версии описывают рабочую среду; требование `package.json` к Node.js остаётся `>=22.12.0`.

## Хостинг и деплой

- Production планируется размещать на российском виртуальном веб-хостинге.
- Timeweb и SpaceWeb рассматриваются как кандидаты; поставщик ещё не выбран.
- Vercel не является целевой production-платформой.
- Для публикации используется содержимое папки `dist`.
- Домен `rgballet.ru` зарегистрирован через REG.RU; в будущем планируется переоформление инфраструктуры на ИП.
- Для тестовой публикации настроен GitHub Pages по адресу `https://dmitrybanin.github.io/RGballet/`.
- Сборка и публикация тестовой версии выполняются через GitHub Actions; целевой production-хостинг в РФ этим решением не заменяется.

## Форма заявки

- Первая версия формы содержит только поля «Имя» и «Телефон».
- Внешний вид формы должен полностью соответствовать макету Figma.
- Сторонний iframe не используется, если он ограничивает воспроизведение дизайна.
- После отправки требуется email-уведомление; уведомление в мессенджер желательно.
- Данные клиентов должны обрабатываться и храниться с учётом требований РФ.
- Решение о собственной админ-панели, собственной CRM или внешней CRM пока не принято.
- До подключения юридических документов и обработчика поля нижней формы доступны только для просмотра, а отправка отключена.
