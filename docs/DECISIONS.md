# Принятые технические решения

## Стек проекта

- Astro.
- HTML.
- CSS без CSS-фреймворков.
- Обычный JavaScript без TypeScript.
- Vanilla JS используется только для меню, модального окна формы, слайдеров и другой интерактивности.
- React, Vue и другие UI-фреймворки на первом этапе не используются.
- Проект собирается как статический сайт командой `npm run build`.
- Результат сборки из папки `dist` должен подходить для обычного виртуального хостинга.

## Порядок разработки

1. Создание Astro-проекта.
2. Подключение шрифтов.
3. Настройка глобальных цветов, размеров и контейнера.
4. Создание `BaseLayout`.
5. Шапка сайта.
6. Первый экран.
7. Остальные секции сверху вниз.
8. Подвал.
9. Мобильное меню.
10. Модальное окно записи.
11. Проверка адаптива в диапазоне от 360 до 1920 px.
12. SEO: `title`, `description`, favicon, sitemap и robots.
13. Яндекс Метрика.
14. Проверка сборки командой `npm run build`.
15. Публикация содержимого папки `dist`.

Сначала должна быть завершена и проверена статическая главная страница. Форма, аналитика и размещение не выполняются на начальном этапе.
