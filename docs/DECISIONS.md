# Принятые технические решения

## Стек проекта

- Astro.
- HTML.
- CSS без CSS-фреймворков.
- Обычный JavaScript без TypeScript.
- Vanilla JS используется только для меню, модального окна формы, слайдеров и другой интерактивности.
- React, Vue и другие UI-фреймворки на первом этапе не используются.
- Проект собирается как статический сайт командой `npm run build`.
- Результат сборки из папки `dist` должен подходить для обычного виртуального хостинга.

## Порядок разработки

1. Создание Astro-проекта.
2. Подключение шрифтов.
3. Настройка глобальных цветов, размеров и контейнера.
4. Создание `BaseLayout`.
5. Шапка сайта.
6. Первый экран.
7. Остальные секции сверху вниз.
8. Подвал.
9. Мобильное меню.
10. Модальное окно записи.
11. Проверка адаптива в диапазоне от 360 до 1920 px.
12. SEO: `title`, `description`, favicon, sitemap и robots.
13. Яндекс Метрика.
14. Проверка сборки командой `npm run build`.
15. Публикация содержимого папки `dist`.

Сначала должна быть завершена и проверена статическая главная страница. Форма, аналитика и размещение не выполняются на начальном этапе.

## Шрифты

- Шрифты хранятся локально в `public/fonts`, без подключения внешних CDN.
- Основной веб-формат — WOFF2, WOFF используется как резервный.
- Для Manrope подключены начертания 300, 400, 500, 600 и 700.
- Для Corvetta подключено начертание 400.
- Для Cormorant Garamond подключено начертание 700.
- Используется `font-display: swap`.
- Право использования Corvetta необходимо подтвердить до публикации сайта.

## Цветовая палитра

- Основной текст: `#232323`.
- Основной фон и инверсные элементы: `#FFFFFF`.
- Основной голубой акцент: `#5BA9E1`.
- Дополнительный голубой акцент: `#5FA8D3`.
- Градиент кнопок строится между `#6DB8FF` и `#3379D7`.
- Обводка основной кнопки: `#CFE7FA`.
- Тень градиентных кнопок: `#357CD8`.
- Техническая подложка фотографий: `#D9D9D9`.
- Локальный чёрный элемент: `#000000`.
- Оба близких голубых цвета сохраняются до визуального сравнения с макетом.
- Угол и положение точек градиента, а также геометрия тени будут добавлены после получения точных параметров из Figma.
